# 🖱️ Auto Clicker
This is an **Auto Clicker** developed in **Java**, featuring a **Swing GUI**.
The program automates mouse clicks, making it useful for repetitive tasks

## 📌 Features
- Simple and intuitive graphical interface (Swing)
- Adjustable click interval
- Set a fixed number of clicks or run infinitely
- Use of multithreading for better performance
- Keyboard shortcut to stop the auto clicker
- Available as **.jar** and **.exe** version

## ⚙️ Technologies Used
- Java 8+
- Swing for GUI
- Robot API for mouse automation

## 🚀 How to run
### 🔹 **Executable (.exe)**
1. Download the `autoClicker.exe` file
2. Double-click to launch the program
3. No java installation required

### 🔹 **Java (.jar)**
1. Make sure you have **java JDK** ≥ 8 installed
2. Download the `autoClicker.jar` file
3. Run it with:
```
java -jar autoClicker.jar
```
## 🎮 Usage
1. Open the program
2. Set the click interval, number of clicks and interval before starting
3. Click start
4. To stop, press the stop shortcut (F4)
